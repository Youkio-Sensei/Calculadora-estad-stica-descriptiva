# Calculadora-estad-stica-descriptiva

Este proyecto es una aplicación desarrollada en Java que implementa funciones estadísticas básicas mediante una interfaz gráfica (Swing). Este proyecto esta pensado para ejecutarse desde cualquier sistema operativo, ya sea Linux,Windows o Mac, en el cual cuentas con el codigo compilado en .jar y tambien con su medio ejecutable .exe
Aparte de esto cuentas con el codigo fuente listo para usar e interactuar 

🧰//Requisitos

Antes de ejecutar el proyecto, asegúrate de tener instalado:

* Java JDK 8 o superior
* (Opcional) Visual Studio 
* Extensión Extension Pack for Java

📁 Estructura del proyecto

* ProyectoEstadistica/
│
├── src/
│   └── Proyecto/
│       ├── Creditos.java
│       ├── (otras clases .java)
│
├── lib/
│   └── (librerías externas, si aplica)
│
└── README.md

▶️ Para su Ejecución en Visual Studio Code

Abre la carpeta del proyecto en VS Code

Asegúrate de tener instaladas las extensiones de Java

Abre la clase Main.java

Presiona Run Java (con esto se ejecutaran todas las clases del proyecto y no una por una con la otro opcion de Run, con esto evitando errores en el terminal)
